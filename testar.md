# MANTO 10 — Guia para rodar o projeto em outra máquina

Este arquivo serve como lembrete para preparar o ambiente do Manto 10 em um computador novo, principalmente nas máquinas da escola.

---

# 1. Programas necessários

Antes de rodar o projeto, verificar se a máquina possui:

- Visual Studio Code
- Node.js
- npm
- Git
- MySQL Server
- MySQL Workbench

Para conferir as instalações, abrir o terminal e executar:

```bash
node -v
npm -v
git --version
